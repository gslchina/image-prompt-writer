# Multi-Panel Rules

For 九宫格, 四格, storyboard, etc.:

- Open with canvas: panel count, rows x columns, equal cells, thin gaps.
- Consistency sentence: same subject, same outfit, same light direction, same face/hair in every panel.
- Then one clause per panel (top-left to bottom-right): position, shot size, action, gaze (some at camera, some not), light if differs.
- Vary shot sizes and gazes on purpose.
- Shared style description once at the end.
- Target total length 1400-1600 characters.
